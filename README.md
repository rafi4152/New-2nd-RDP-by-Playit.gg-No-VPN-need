# 🚀 Ultra-Fast Playit.gg RDP (Multi-User & Auto-Optimized)

এই রিপোজিটরিটি ব্যবহার করে আপনি সম্পূর্ণ বিনামূল্যে GitHub Actions এর মাধ্যমে একটি হাই-স্পিড এবং ল্যাগ-ফ্রি Windows 11 RDP তৈরি করতে পারবেন। এটি বিশেষ করে স্লো ইন্টারনেট এবং মোবাইল নেটওয়ার্ক (যেমন: 4G/5G রাউটার) এর জন্য অপটিমাইজ করা হয়েছে।

## ✨ মূল ফিচারসমূহ

- **⚡ অটো-কোয়ালিটি অ্যাডজাস্টমেন্ট:** ইউটিউবের মতো ইন্টারনেটের স্পিড কমে গেলে RDP এর কোয়ালিটি স্বয়ংক্রিয়ভাবে কমে যাবে, ফলে ভিডিও আটকে যাবে না বা ল্যাগ করবে না (H.264/AVC444 কম্প্রেশন এনাবেলড)।
- **👥 মাল্টি-ইউজার সাপোর্ট:** দুটি আলাদা অ্যাকাউন্ট তৈরি করা হয়েছে:
  - `Admin` (পিসির জন্য ফুল কন্ট্রোল)
  - `Mobile` (স্মার্টফোন থেকে চালানোর জন্য)
- **🌍 ভিপিএন/Tailscale মুক্ত:** Playit.gg টানেল ব্যবহারের কারণে কানেক্ট করার জন্য আপনার ডিভাইসে কোনো ভিপিএন চালু রাখার প্রয়োজন নেই।
- **⚙️ অটো স্ক্রিপ্ট এক্সিকিউশন:** সার্ভার চালু হওয়ার সাথে সাথেই আপনার প্রয়োজনীয় `Downloads.bat` ফাইলটি স্বয়ংক্রিয়ভাবে রান হয়ে যাবে।

## 🛠️ সেটআপ গাইড (নতুনদের জন্য)

### ধাপ ১: Playit.gg সিক্রেট কি সংগ্রহ
১. [playit.gg](https://playit.gg/) ওয়েবসাইটে গিয়ে একটি ফ্রি অ্যাকাউন্ট তৈরি করুন।
২. ড্যাশবোর্ড থেকে আপনার **Secret Key** টি কপি করে নিন।

### ধাপ ২: গিটহাবে সিক্রেট যুক্ত করা
১. এই গিটহাব রিপোজিটরির **Settings** এ যান।
২. বামদিকের মেনু থেকে **Secrets and variables** > **Actions** এ ক্লিক করুন।
৩. **New repository secret** বাটনে ক্লিক করুন:
   - **Name:** `PLAYIT_SECRET_KEY`
   - **Secret:** আপনার কপি করা Playit Key টি পেস্ট করুন।
৪. **Add secret** এ ক্লিক করে সেভ করুন।

### ধাপ ৩: RDP সার্ভার চালু করা
১. গিটহাবের **Actions** ট্যাবে ক্লিক করুন।
২. বাম পাশ থেকে `win 11 + Playit + MultiUser + Auto-Optimize` ওয়ার্কফ্লোটি সিলেক্ট করুন।
৩. ডানপাশে **Run workflow** বাটনে ক্লিক করুন। 
৪. ১-২ মিনিট অপেক্ষা করুন এবং আপনার [Playit.gg Tunnels Dashboard](https://playit.gg/tunnels) এ চেক করুন। সেখানে আপনি কানেক্ট করার জন্য একটি ডোমেইন এবং পোর্ট পেয়ে যাবেন (যেমন: `xyz.ply.gg:12345`)।
